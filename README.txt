TRAUMAGUIDE MVP PROTOTYPE v0.1

Files:
- index.html: responsive app interface and interactive learning modules
- manifest.json: installable web app metadata
- sw.js: basic offline caching for the app shell

RUN LOCALLY:
Open index.html in a modern browser. Search and module navigation work locally.

PWA INSTALLATION:
To test installability/offline support, host these files over HTTPS (or run a local development server). Open the hosted URL in Chrome on Android and use the browser's Install app / Add to Home screen option.

IMPORTANT:
This is an independent educational prototype. The tibial nailing content is introductory draft material, not a surgical technique guide and not clinically reviewed. Do not use it for patient care. Before public or professional release, have every module reviewed by qualified clinicians, add traceable current references, check copyright/licensing, privacy, accessibility and regulatory requirements. Do not use employer logos, confidential documents, proprietary images or manufacturer-specific claims without written permission.
